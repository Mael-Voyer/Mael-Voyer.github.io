*TauREx beginers tutorial:*

The tutorials aims to demonstrate how to run simple retrievals with TauREx. I focus on the utilisation of TauREx, not in the installation of the multiprocessing dependencies. This tutorial is aimed to make anyone understand the basics of TauREx and atmospheric retrievals. I provide detailed examples to start creating atmospheric forward model, then running some retrievals showcasing some of the basic capabilities of TauREx. I also include additionnal notebooks to visualize cross-sections, atmospheric models etc.
